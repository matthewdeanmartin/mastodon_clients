Description: A factual directory of Mastodon-compatible web clients, with feature comparisons, licensing, deployment models, and maintenance signals.

Mastodon has more than one web client. Which one you use is usually decided by
whichever your server administrator installed, and that is not always the one
that suits you.

This site is a directory of the alternatives. It records what each client does,
under what licence, funded how, maintained how actively, and for whom it seems
to be built &mdash; as structured facts rather than as opinion.

## How this site works

Facts live in structured records, one file per client, in a
[public repository](https://github.com/matthewdeanmartin/mastodon_clients). The
pages you read are generated from those records, so a correction is a small,
reviewable change rather than an edit buried in prose.

**Ratings are arithmetic.** They are computed by code from the structured data,
they are reproducible by anyone with the repository, and no language model
assigns one. [The formula is published in full](/methodology/scoring/). It is
also a blunt instrument, which is why the audience pages and the directory
filters matter more than sorting the field by stars.

**Maintenance is never one number.** A quiet month is not abandonment and a dead
domain is not a shutdown announcement. Several independent signals are collected
by hand, synthesised conservatively, and shown on each client's page so you can
see what the conclusion rests on.

**Nothing here is written to sell you anything.** Reviews try to separate what a
client does from what we make of it, and to say plainly when we do not know
something rather than filling the gap.
