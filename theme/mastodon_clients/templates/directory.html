Reading this table

Rating
Computed from structured metadata: feature breadth, maintenance signals, deployment and documentation, support resources, and accessibility. It is reproducible from the data in this repository, and it deliberately does not capture every reader's priorities. The audience pages and the filters above are more useful than sorting by stars.
Maintenance
Synthesised from several independent signals. No single signal — not a dead domain, not a quiet month — is enough to call a project unmaintained. Each client's page shows the underlying observations.
Source
Whether source is published, kept separate from which licence it carries. The two are different facts and this site does not conflate them.
Deployment
How you obtain the client. A separate field, shown on each client's page, records whether the client works with any Mastodon-compatible server or requires you to deploy one.
